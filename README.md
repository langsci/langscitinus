Occasional small improvements to the Libertinus Serif fonts. 
A lot of obscure glyph-diacritic combinations don't get displayed correctly in Libertinus. Additionally, rare letters that are used in lesser-known languages may not exist at all as Libertinus characters.
This can be a problem when publishing books in or about these lesser-known languages. When that happens we update the fonts and collect all cumulative changes in this repo. We call the result _Langscitinus_ (a portmanteau of _LangSci Press_ and _Libertinus_).
As of September 2026, the Libertinus repo hasn't been updated in a while which is why we decided against requesting the creator of Libertinus to incorporate our changes into the "official" Libertinus Serif fonts.
Langscitinus is free to use for everyone.
